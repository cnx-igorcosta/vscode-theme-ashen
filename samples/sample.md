# Ashen

Tema **quase-monocromático** para VS Code — fundo neutro frio, foreground bege
e desvios sutis de matiz. Use com uma fonte de boa legibilidade em pesos leves.

## Paleta

| Papel | Hex | Observação |
| --- | --- | --- |
| Fundo | `#0F0E0F` | quase preto |
| Foreground | `#e3dac9` | bege *bone* |
| Keywords | `#937f88` | malva |
| Tipos | `#93867f` | terroso |
| Strings | `#88937f` | sálvia |

> O truque: as três cores de token são permutações dos mesmos canais RGB.

1. Instale com `code --install-extension ashen.vsix`
2. Abra a paleta: <kbd>Ctrl</kbd>+<kbd>K</kbd> <kbd>Ctrl</kbd>+<kbd>T</kbd>
3. ~~Ajuste o `settings.json`~~ — não é mais necessário
